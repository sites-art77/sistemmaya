MAYA GARDEN PRO — COMO PUBLICAR (2 minutos)
============================================
1. Crie conta em https://github.com e clique em "New repository".
   Nome sugerido: maya-garden | Deixe Public | Create repository.
2. Clique em "uploading an existing file".
3. Arraste TODA esta pasta (todos os arquivos e subpastas) para a página.
   Inclua os itens ocultos: .github, .gitignore, .nojekyll
   (no Explorer: Exibir > Mostrar > Itens ocultos).
4. Clique em "Commit changes".
5. Vá em Settings > Pages > "Build and deployment" > escolha "GitHub Actions".
6. Em 1-2 minutos o endereço aparece na tela, tipo:
   https://SEU-USUARIO.github.io/maya-garden/

Funciona em Android, iPhone e computador, inclusive offline após a 1ª visita.
Dúvidas? Fale com quem fez o sistema.

BACKUP DOS DADOS
================
Como os dados ficam salvos no navegador, abra Configurações > Backup dos dados
e clique em "Baixar backup" regularmente. Para levar o sistema a outro aparelho,
use "Restaurar backup" e selecione o arquivo .json salvo.

SINCRONIZAÇÃO EM NUVEM
======================
Em Configurações > Sincronização em nuvem, crie uma conta com e-mail e senha
ou entre com uma conta já criada. Depois de entrar, use "Enviar para a nuvem"
para guardar os dados atuais e "Baixar da nuvem" para trazer os dados para outro
aparelho. O sistema continua funcionando offline e mantém o backup local.
Não compartilhe sua senha; cada conta acessa somente os próprios dados.

SE NÃO CARREGAR (tela em branco / 404 / travado no "Carregando")
================================================================
1. Primeiro abra no ar: https://SEU-USUARIO.github.io/maya-garden/diagnostico.html
   Ele testa tudo sozinho e diz o que falhou. Copie o relatório (botão).
2. Causas mais comuns e solução:
   a) Esqueceu a pasta .github (ela é oculta): sem ela o deploy não roda.
      Reenvie marcando "Itens ocultos" no Explorer ou use GitHub Desktop.
      Em Settings > Pages > Actions deve existir um deploy verde.
   b) Subiu a PASTA em vez do CONTEÚDO: o index.html precisa ficar na raiz
      do repositório (fora de qualquer subpasta).
   c) Repositório Private em conta grátis: Pages exige repositório Public.
   d) Tela branca/travada: abra com Ctrl+F5 (limpa cache) e veja se aparece
      faixa vermelha de erro no topo — anote o texto.
   e) Internet bloqueando o Tailwind (CDN): o sistema liga um CSS reserva
      sozinho, mas confira no diagnóstico a linha "Tailwind CSS".
3. Cada nova subida pode exigir 1 Ctrl+F5 para largar o cache antigo.
